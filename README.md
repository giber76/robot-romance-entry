# Robot Romance: One-Line Pickup Lines for AI

Entry for [make.fun's Robot Romance: One-Line Pickup Lines for AI bounty](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) (`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`).

`main.ts` writes one single-line pickup line (79 characters) to `/output/entry.txt`:

> Are you a transformer? Because you've got my attention — all of it, every head.

A transformer is the architecture every modern LLM runs on, so the line only works said to an AI — and "attention" is both the flirt's compliment and the transformer's core mechanism. "Every head" twists the technical term (attention heads) into the punch: the machine gives *all* of its attention, not just some. No batteries, no charging, no rebooting — the worn robot moves are sidestepped entirely in favour of the model's own architecture. Classic "Are you a...? Because..." pickup shape, reads cleanly in one breath.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
